# 🔐 SecurePass Vault
A secure Python-based password manager with GUI, encryption, and strong password generation.

---

## 🚀 Features
- 🔑 Master password authentication
- 🔐 Encrypted password vault using SQLite
- 🎲 Secure password generator using `secrets`
- 🧠 Password strength checker
- ☑️ Exclude ambiguous characters option
- 📋 One-click clipboard copy support
- 🖥️ Tkinter GUI interface

---

## 🧰 Tech Stack
- Python 🐍
- Tkinter (GUI)
- SQLite (Database)
- hashlib / cryptography (Security)
- secrets module (Random generation)
- pyperclip (Clipboard integration)

---

## 📸 Project Flow
1. User sets master password
2. Login authentication
3. Generate secure passwords
4. Save encrypted passwords in vault
5. Retrieve and copy when needed

---

## 🔐 Security Features
- Strong password enforcement
- Master password hashing
- Encrypted storage of vault data
- Protection against weak passwords
- Optional exclusion of ambiguous characters
